# 山东地质实地考察点

https://wadesha.github.io/shandong-geo-sites/

据《山东省区域地质志》（山东省地质矿产局，1991，地质出版社）601 页文字层提取，并经联网逐条核实行程位置、坐标、保护级别与地质年代后重建的实地考察点图谱。

- 81 处真实点位，分属 10 个构造区段
- 15 条地质原理，每处点位均挂原理标签
- 11 处国家地质公园名录与出处清单
- 每处点位页为一篇长读：地质格架位置、现场看点逐条、成因解读、志书原文摘录、实地提示、常见疑问、相邻点位串联、原理全文与术语表；
  正文合计约 354,536 字，平均每处约 4,376 字

站点为纯文本静态站：无图片、无 emoji、无第三方脚本，明暗双主题，全文可检索。

本站由私有构建管线生成，仓库只存放发布产物。
