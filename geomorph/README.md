# 山东地貌专题

https://wadesha.github.io/shandong-geo-sites/geomorph/

据《山东省区域地质志》（山东省地质矿产局，1991，地质出版社）601 页文字层提取，并结合地貌学原理重建的山东省地貌点位图谱，是「山东地质实地考察点」的姊妹专题。

- 45 处地貌点位，分属 9 类地貌
- 14 条地貌原理，每处点位均挂原理标签
- 每处点位页为一篇长读：地貌格架位置、现场看点逐条、成因解读、志书原文摘录、实地提示、常见疑问、相邻点位串联、原理全文与术语表；
  正文合计约 190,266 字，平均每处约 4,228 字
- 志书原文逐处标明资料性质：点位记述 / 区域背景 / 专题相关 / 无对应
