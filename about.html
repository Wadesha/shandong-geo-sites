读法说明How to use this site

这是什么

把《山东省区域地质志》里能落到实地的内容抽出来，重建为 81 处真实点位：每一处都写明行政区位、地层与岩体、时代（含年代学方法给出的具体数值）、在志书中的页码、现场现状与保护级别，以及它背后对应的地质原理。站点分三层：区段（10 个构造单元）→ 点位（81 处）→ 原理（15 条）。

一处点位页里有什么

每处点位页是一篇约两千字的完整长读，不是卡片。自上而下依次是：

  1. 速览表与开篇：行政区位、坐标、地层岩体、时代、保护级别、志书页码，再用一段话讲清这处是什么、为什么特别、今天什么状态。
  2. 它在地质格架里的位置：这套岩石或构造属于哪个单元、什么时代背景、与上下左右的地层是什么关系——回答「为什么偏偏在这里」。
  3. 现场看点：逐条写明到现场看什么形态、什么颜色、什么结构，以及凭什么这样判断。
  4. 成因：把现象还原成过程——谁提供物质、谁提供热量、什么条件下沉淀或变质。
  5. 志书原文：从志书 601 页文字层里按页码与关键词自动定位、原文照录的段落，附页码链接，可跳转到全文阅读版核对上下文。
  6. 今天去看与实地提示：现状、到达方式、能否敲样、有无保护限制与安全注意。
  7. 常见疑问：读者真会问的问题，例如「为什么别处没有」「这个年龄是怎么测出来的」。
  8. 串起来看：与同区段其它点位组成一条路线，说明先看哪处再看哪处、组合起来能看出什么。
  9. 背后的原理与术语速查：原理原文完整给出；术语按本页实际出现的内容自动挂载，不堆砌无关词条。

三条读法

  1. 按空间读：从首页进区段页，一个构造单元一个构造单元地看，适合建立整体格架。
  2. 按地名检索：首页总表支持按区段筛选与关键词检索，输入「蒙阴」「榴辉岩」「金伯利岩」都能直接命中。
  3. 按原理读：从原理页进去，会列出引用这条原理的全部点位——同一原理下横跨几个区段，最能看出山东地质的连续性。

四条限制

  1. 坐标精度不一：标「约」的按行政区位估读；未标坐标者一律注明。实地导航请以村镇名复核，不要直接信小数位。
  2. 页码是 PDF 页：点位页上的「pXX」指志书文字层 PDF 的第 XX 页，与印刷页码可能相差数页（原刊页码另行标注于阅读版中）。
  3. 志书原文是机器摘录：那一节由关键词定位后自动截取，未经人工逐句校读，可能出现上下文缺失或 OCR 残留；正式引用前请回到全文阅读版核对。
  4. 志书时效：志书 1991 年出版，部分「解释」已被改写。本站区分「观察」与「解释」，过时之处直接标注，不给旧结论背书。保护级别与开放状态会随年份调整，出行前请以主管部门最新公告为准。

技术特征

纯文本静态站：无图片、无 emoji、无第三方脚本与字体，全文可检索、可打印；单页体积均在数十 KB 量级；样式与脚本各一份，明暗双主题随系统并可手动切换。整站由结构化数据一次性渲染生成，改数据后重跑即可全站重建，因此不会出现「改了某页忘改另一页」的不一致。
